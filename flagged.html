9. Repository irregularities found while integrating

  • Build A's write-ups are templated. 32 of its predictions reuse one sentence skeleton ("… entered this match with a points percentage of …"). They passed that build's own word-count check but not the brief's "not repetitive, not robotic" requirement, so they are not counted as predictions here.
  • The published row count and the data file disagree in build A. docs/ describes 144 rows across 15 sports, while data/rows.json holds 137 rows across 11 sports. A later commit is recorded in the repo's own audit as having overwritten that file. The data file is what this board reads.
  • Duplicate fixture lists across builds. The same Tennis and Darts fixtures appear in builds A, B, D and G. This board merges them; the separate dashboards do not, so totals across dashboards are not additive.
  • Greyhounds, golf and motor racing have no head-to-head markets. Builds A and B treat them as futures-only sports; where a race is listed there is no originated pick.
  • Two official pages could not be read today (pdc.tv's 18 Oct draw page and wst.tv's match centre), so those citations are recorded as unreadable rather than passed — see Audit.

How lines are originated

We do not copy bookmaker prices. For each match we estimate fair probabilities using a transparent model: ELO + recent form (last 10) + head-to-head (last 3 years) + home/venue adjustment + travel/rest. Probabilities are converted to decimal odds with a 3.5-4.5% margin (overround) to mirror a fair book. Handicaps are set to balance implied win prob to ~50% each side; totals are set from pace/conditions models. High-confidence picks require ≥58% model edge and corroborating form.

Flagged rows are not removed; they are shown and explained on the Flagged for Review page.

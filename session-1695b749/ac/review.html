Findings on the files that decide what gets published

.github/workflows/validate.yml

The CI gate every branch runs: rebuilds the session-74f9613e build and fails on any diff anywhere in the tree.

The last step compares the whole working tree, not just the generator's own output, so any committed page that a generator would rewrite fails the build. That is a strong anti-staleness gate and a blunt one: a hand-edited root page survives only while no generator claims the same path. This board's pages are new files under session-1695b749/ac/, so the gate stays green and the board does not fight the generator.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/.github/workflows/validate.yml

.github/workflows/pages.yml

The deploy pipeline: rebuilds the master board, verifies it, then refuses to deploy if the committed board is stale.

The stale check diffs only board/, data/master.json and data/master_conflicts.json, so a master-board rebuild has to be committed before Pages will publish. That is exactly the failure this repository hit when the committed board drifted from the generators, and it is the reason the master board was regenerated and committed this week. LoL, NHL and MLB desks are outside this gate, which is why a desk can ship without touching the master board.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/.github/workflows/pages.yml https://github.com/buffedlizard55-lab/OLBG4/blob/main/tools/build_master.py

tools/build_master.py

Deduplicates the committed work of six builds into data/master.json.

Cluster keys are sport plus both team names plus a one-day date tolerance, and the winning record inside a cluster is chosen by evidence: pick, then prediction, then official source, then build-verified, then backbone rank. Losing records are kept in cross_build rather than dropped, and out-of-scope rows stay in the file with in_scope false and a reason. The current file holds 336 rows of which 331 are in scope.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/tools/build_master.py https://github.com/buffedlizard55-lab/OLBG4/blob/main/data/master.json

tools/build_master_site.py

Renders the master board into board/ and, when pointed at the repository root, the root pages.

Run with BOARD_OUT=board it is confined to board/, which is what the Pages workflow does. Run without that variable it writes the root index and the topic pages, which is the collision this board records as AF-12: two generators and a hand-maintained root all claim index.html, and no CI step diffs the root against either generator.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/tools/build_master_site.py https://github.com/buffedlizard55-lab/OLBG4/blob/main/index.html

scripts/audit_publication.py

Repository-wide structural audit of every local link across all builds.

The module docstring is unusually honest: it states that it never equates a URL with factual verification and that external URLs are listed for manual review rather than requested. Running it without --check rewrites audit/index.html and audit/report.json, which dirties the tree, so the safe invocation is --check after a clean checkout. Its report is the basis for the 12,000-plus local targets quoted across boards.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/scripts/audit_publication.py https://github.com/buffedlizard55-lab/OLBG4/blob/main/audit/report.json

pipeline/

The shared model package: providers, markets, records, predictions, verification and a selftest.

The split is clean enough to reuse: providers normalise upstream payloads, markets converts probabilities into prices, records handles identity, and verify asserts the published invariants. The selftest is the cheapest gate in the repository and runs without network access, which is why it is worth running before any larger rebuild.

https://github.com/buffedlizard55-lab/OLBG4/blob/main/pipeline/model.py https://github.com/buffedlizard55-lab/OLBG4/blob/main/pipeline/markets.py https://github.com/buffedlizard55-lab/OLBG4/blob/main/pipeline/selftest.py

scripts/session-e5f2dad3/collect.py

The collector that produced the capture manifest this board reads.

Every entry records URL, HTTP status, byte count, content type, elapsed time and SHA-256 of the body as served. That is the difference between a citation and a claim: this board re-hashes each file against the manifest before parsing it, so a tampered or truncated payload aborts the build instead of quietly changing a price.

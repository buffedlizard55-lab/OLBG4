How the board is organised

Data only from official pages. Each priced row names the governing body, league or tour page it was built from, and the captured file is hash-checked against the run manifest before use. Bookmaker listings are used only to see which matches exist.
Gaps are published, not filled. Where an official page did not publish a readable number, the row stays blank and appears on the flagged page. Nothing is inferred to make a table look complete.
Every price on this site is originated by this desk from the official figures quoted on the row. Nothing is copied from a bookmaker. Rows without an official numeric input stay blank and are listed on the flagged page.

One conflict this board found but did not resolve

Two published gates disagree about blanking a source link, and it is not this board's call to make. The brief says both "every table row must have a source link to an official site" and "if a value can't be confirmed from an official source, leave it blank and flag it unverified". Board 082d3c16 resolved that tension toward blanking: 41 hub rows now have an empty sourceUrl, with the previous value preserved in priorSourceUrl and the row flagged. session-07a080b9/audit.py (Board F) treats a missing sourceUrl as a hard FAIL and reports all 41.

Both readings are defensible, so this board recorded the conflict rather than "fixing" it in either direction — overturning the owning board's blanking would discard its verification work, and editing Board F's audit script would rewrite another board's findings. It is surfaced as a non-blocking NOTE in check_all.py and logged in COORDINATION.md for the two boards to settle. It does not block deployment: pages.yml runs tools/verify_master.py, which passes, not Board F's audit.

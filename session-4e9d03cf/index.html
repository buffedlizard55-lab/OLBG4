How this review works

Rules that prevent silent promotion

  1. Official source link: shown only if the canonical master classifies the source as official. A blank means blank; S1 does not substitute a guess.
  2. Current view: only in-scope head-to-head fixtures dated 2026-10-22 or later are candidates. Historical, market-note, incomplete and excluded rows remain visible in the full audit table.
  3. High confidence: templated high-confidence copy is held. The original official link remains available on the Flagged page, but the prediction is not treated as compliant unique writing.
  4. Focus range: the pipeline’s 70%+ / −250 to +10000 American-odds subset is reported exactly as supplied; no artificial pick is added if it is empty.

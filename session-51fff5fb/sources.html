Official coverage gaps

Gaelic Sports

gaa.ie serves a client-side app: the captured page carries no fixture list, so GAA club and county matches are listed from OLBG only and cannot be priced from an official table.

Official source / coverage gap

Greyhounds

The Greyhound Board of Great Britain results API returns completed races; no forward racecard with traps, going and runners was retrievable, so no greyhound line is originated.

Official source / coverage gap

Cricket

ICC publishes team rankings on a client-rendered page and no machine-readable fixture list; domestic boards (Cricket Australia, NZC, ECB, BCCI) likewise serve app shells. Fixtures appear from OLBG only.

Official source / coverage gap

Rugby League

rlwc2026.com and nrl.com return app shells with no fixture JSON; no league table was retrievable to build a strength input from.

Official source / coverage gap

Rugby Union

unitedrugby.com and premiershiprugby.com return client-rendered match centres (5.7 KB shell); no table or fixture array was captured, so URC and Premiership fixtures stay unpriced.

Official source / coverage gap

Darts

pdc.tv returns the same 1.24 MB JavaScript shell for every route, so the draw is not machine-readable. The PDC participant API gives Order of Merit rankings but not tonight's pairings, so no line is made from ranking alone.

Official source / coverage gap

Handball

EHF Champions League and the German/Spanish/French leagues render fixtures client-side; the Danish Herreligaen table is machine-readable but no OLBG-listed fixture in the window involved two Danish sides, so the handball rows stay unpriced.

Official source / coverage gap

Volleyball

Italian SuperLega, Polish PlusLiga and Czech Extraliga tables were captured, but the Italian season is one match old and the Polish table could not be reconciled to a single fixture in the window, so only rows with a reliable sample are priced.

Official source / coverage gap

Golf

Golf is an outright tournament market, not a two-sided match. OLBG closes its golf tip markets when round one starts, so in-play weeks show no OLBG listing; the outright shown comes from the PGA Tour leaderboard only.

Official source / coverage gap

Motor Racing

Formula 1 and MotoGP publish a round-by-round calendar but not a machine-readable outright market; the race outright is derived from the official drivers' championship only.

Official source / coverage gap

Tennis

The WTA API returns match objects; where an official singles ranking is missing for either player the row is left unpriced rather than guessed.

Official source / coverage gap

Basketball

NBA.com and the NBA CDN return HTTP 403 to this capture, so only EuroLeague and EuroCup fixtures are priced from official data.

Official source / coverage gap

Snooker

snooker.org carries the draw and WST publishes rankings, but the Northern Ireland Open was in play at capture, so only matches with both players ranked are priced.

Official source / coverage gap

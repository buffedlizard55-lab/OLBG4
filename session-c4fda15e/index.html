What this board did

  1. Reverse-engineered OLBG’s listing. Each OLBG sport hub is a SvelteKit page that embeds its listing (tips:[…], tournaments:[…]) with a machine timestamp per event; the server builds it from /sports/<Sport>/top_tips?paginate=1-100&include_expired=1. That API and OLBG’s /api/svelte “Load More” endpoint sit under robots-disallowed paths, so they were not called — the inventory uses only the 18 public hub pages. Every hub returned fewer than 100 rows, so the embedded arrays hold the full listing the hubs render. OLBG lists only events that already carry tips. Details.
  2. Reconciled every OLBG match row against an official page or feed (ATP/ProTennisLive, WTA, PDC, NBA.com, EuroLeague, LNR, URC, MLB, Liiga). Row-by-row table.
  3. Originated our own lines from official numeric inputs only (rankings, Order of Merit, standings, points/runs/goals for and against), with handicap/total markets where the inputs support them. All lines.
  4. Flagged everything unconfirmed, mismatched or irregular. Flagged for Review.

Board AD independently re-audits Board AB's originated desk (data/session-1695b749/desk.json): it checks every row's source domain is an official league API (api-web.nhle.com / statsapi.mlb.com / esports-api.lolesports.com), recomputes fair American odds from model probability, recomputes confidence (High requires prob ≥0.70 AND fair odds −250…+10,000; Medium ≥0.55), checks High predictions are ≥30 words, unique, and inside the odds window. Failures go to Flagged, values are never filled in. Live spot re-verification (NHL schedule/standings, MLB World Series) was re-read from official APIs on 2026-10-22 — see Sources.

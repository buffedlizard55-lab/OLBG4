Method

Scope

This board audits; it does not originate lines, picks or predictions. It reads the committed data of each build (data/rows.json, data/board.json + data/predictions.json, data/session-74f9613e/*.json, data/matches.json, session-4afef1af/data/*.json) and never edits another board's files.

Source classification

A domain is official if it belongs to the league, governing body, national federation or the official data feed of the competition (list in scripts/session-e1e0c27e/audit.py: nba.com, nhl.com, api-web.nhle.com, mlb.com, statsapi.mlb.com, atptour.com, wtatennis.com, pdc.tv, wst.tv, icc-cricket.com, cricket.com.au, pcb.com.pk, nzc.nz, cricsa.co.za, acb.af, eurohandball.com, ihf.info, fivb.com, volleyballworld.com, nrl.com, unitedrugby.com, premiershiprugby.com, world.rugby, pgatour.com, lpga.com, europeantour.com, bwfbadminton.com, ittf.com, fftt.com, afl.com.au, lolesports.com, valorantesports.com, gbgb.org.uk, galwaygaa.ie, gaacork.ie, formula1.com, euroleaguebasketball.net). olbg is the OLBG event page — an aggregator, useful to define the sport universe but not an official fixture source. Everything else is secondary (ESPN, BBC, Sky, Wikipedia, cricinfo, snooker.org, betting blogs, ticket/travel sites, IOC news, host-city pages).

Row verdict

“official source present” if any link on the row is official; “OLBG only” if the only links are OLBG; “secondary source only” otherwise. The verdict says nothing about whether the value is right — that is what the spot checks are for.

Spot checks

Rows were re-read on 21 Oct 2026 using web search and page fetch (the sandbox itself can reach only GitHub/npm/PyPI hosts). For each, the page shows the build's value, the source's value and the URL, and a result of confirmed / partial / contradicted / unverifiable. The sample covers every build and deliberately targets the rows whose sources looked weakest.

Cross-build matching

Team names are lower-cased and stripped of punctuation; kick-off times are converted to the US-Eastern calendar date so NBA/NHL/MLB rows from different builds line up. A conflict is recorded only when two builds name different teams as the winner (a totals pick is not a conflict).

Limits

18 of 459 rows were spot-checked; the domain check is mechanical; secondary sources were not treated as proof even when they agreed with each other. Every unverified claim is left as published and listed on the Flagged page rather than corrected.

What is verified, and how

Each official row is parsed from a committed payload whose SHA-256 is recorded in the source register. The build re-hashes every file it reads and refuses to publish a row whose hash does not match. Only participants, date, UTC start time and venue are taken from the official payload; every price is computed by our model from the official season table.

Where no official capture exists, the row is published as an OLBG listing with blank venue, no price, no pick and a flag on the Flagged for review page. Nothing is inferred, and no value is copied from a previous session's dataset.

Markets investigated

  • Match total — originated for NHL and MLB from official goals/runs for and against.

The odds-window tension, stated plainly. At fair odds a 70% chance is 1.43 (−233) and a 71.4% chance is exactly −250. A pick can therefore only be both “over 70%” and “no shorter than −250” inside the 70.0–71.4% band. We publish the 3 high-confidence picks that fall inside the requested −250…+10,000 window (68.0–71.4% model probability) and report the stronger-but-shorter prices separately on Flagged rather than moving the goalposts.

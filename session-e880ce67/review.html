What this review is, and is not

This is a structural audit of the repository's consolidated data file: it checks dates, sources, confidence labels, prediction length and vocabulary, sport scoping and duplicate identity. It does not re-fetch every fixture, so a row can pass the structure check while its price is wrong — that is why each finding links the official page it concerns. Findings are reported, not silently repaired, because the consolidated file belongs to the whole repository.

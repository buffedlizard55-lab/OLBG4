Sources that worked and sources that did not

Every URL below was requested by the capture job; the table on Sources shows the exact HTTP status for each. The pattern is consistent with previous boards: JSON APIs from the NHL, MLB, EuroLeague, WTA and Liiga work, while several league sites return JavaScript shells (URC, WST, PDC, NBA, NRL) and were not used as evidence.

No line without a feed. Golf listed no event on the OLBG hub at capture and no official field feed was reachable, so Golf carries zero rows rather than an invented outright market. Greyhounds returned only completed-race results (the pre-race endpoints 404), so no upcoming race is priced. The same applies to Darts, Gaelic Sports, Rugby League, Snooker and Rugby Union.

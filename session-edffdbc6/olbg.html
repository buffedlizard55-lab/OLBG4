What OLBG actually publishes, read from the site itself: the fifteen in-scope sport hubs, the match objects embedded in each page, and the market vocabulary attached to them.

How the site is built

  • The sports hubs are server-rendered (SvelteKit). Each listed match is a schema.org/SportsEvent object carrying itemprop="name" (the pairing), itemprop="startDate" (ISO-8601 kick-off) and a canonical event URL of the form /betting-tips/<Sport>/All_<Sport>/All_Events/<Home>_vs_<Away>/<id>?event_id=….
  • Tips themselves are attached to those events, not to a separate fixture database, which is why the hub shows only events that currently have tips.
  • robots.txt disallows 51 path prefixes for * (API, sports, search, tipster, cache, and others). This desk only fetches public hub pages at a 1 request/second rate.
  • Sub-hub URLs that returned their own page this capture: NHL, NBA, EuroLeague, MLB. Deeper sub-hubs are link-only.

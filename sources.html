Trust hierarchy we follow

  1. Governing body domain (e.g., nba.com, mlb.com, atptour.com, wtatennis.com, nhl.com, pdc.tv, pgatour.com, lpga.com, bwfbadminton.com, worldtabletennis.com, fivb.com) — always the source of record.
  2. Official competition microsite (e.g., world.rugby/tournament/*, euroleaguebasketball.net) — accepted as official when linked from governing body.
  3. Secondary summaries (BBC Sport, ESPN, Wikipedia pages sourced to the official body, Sky Sports) — used for form/head-to-head when official stats page is paginated; always paired with a primary link.
  4. Blocked or not published → field flagged blank, reason on Flagged page.
If you find an official source contradicts a row, please open a GitHub issue with the URL and correction. The dataset is intentionally human-reviewable.

Trust hierarchy we follow

  1. Governing body domain (e.g., nba.com, mlb.com, atptour.com, wtatennis.com, nhl.com, pdc.tv, pgatour.com, lpga.com, bwfbadminton.com, worldtabletennis.com, fivb.com) — always the source of record.
  2. Official competition microsite (e.g., euroleaguebasketball.net, wst.tv, pcb.com.pk) — accepted as official for its own competition.
  3. Not used for values — BBC, ESPN, Sky Sports, Wikipedia, OLBG and other secondary or market sites. Earlier sessions used some of these as row sources; those rows are now unverified in this hub.
  4. Blocked, JavaScript-only or not published → the value is blank, the row is flagged, and the reason is on the Flagged for Review page.
If you find an official source contradicts a row, please open a GitHub issue with the URL and correction. The dataset is intentionally human-reviewable.
